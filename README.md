## 📖 简介

在日常群聊或好友交流中，经常会出现诸如「帮忙垫付打车费」、「饭后 AA 借钱」、「买咖啡代付」等小额借贷场景。往往容易遗忘、数额记不清、缺乏凭据，甚至引发误会。

**`astrbot_plugin_debt_ledger`** 专为解决这一痛点而开发。它引入了严密的**双方确认机制**、**自然语言 @机器人 智能交互** 以及 **精确到秒的 SQLite WAL 流水账本**，并基于用户全局 QQ 账号实现**跨群自动对账与冲抵（Netting）**。

---

## ✨ 核心特性

- 🤝 **双向申请与双方确认机制**：
  - 杜绝单方面恶意记账。无论是借出、借入还是还款，均生成独立短单号（如 `#101`）并在群内通知对方；
  - 必须由被申请人发送 `/同意` 或 `/拒绝` 后才真实入账生效；
  - 支持超时自动失效（默认 10 分钟）以及发起人主动撤销。
- 🤖 **全方位自然语言 @机器人 支持**：
  - 像和真人说话一样直接 `@Bot 我借给 @张三 100元 吃饭AA`，自动提取对象、金额、事由；
  - 内置本地零延迟规则引擎 + AstrBot 原生 `LLM Function Calling` 双重驱动。
- 🕒 **精确到秒的真实对账流水（SQLite WAL）**：
  - 每一笔借款和还款都详细记录发起时间与确认生效时间（`YYYY-MM-DD HH:MM:SS`），支持随时追溯。
- 🌐 **基于 QQ 账号绑定，跨群全局自动对冲（Netting）**：
  - 自动双向抵扣。例如 A 借给 B 100 元，后续 B 借给 A 30 元，系统自动冲抵为 **B 净欠 A 70.00 元**；
  - 无论在哪个群聊或私聊中发生，只要双方 QQ 号一致，即可一键查询两人的跨群累计净债务及个人的全局借贷大盘。
- 📊 **美观结构化的卡片排版**：
  - 包含申请卡片、确认结余卡片、双人历史对账单、个人全局大盘等。

## 💬 自然语言使用指南（@机器人）

无需输入斜杠指令，直接在聊天中 **@机器人 + 自然语言**（支持免@直接使用绑定的外号）：

| 使用场景 | 对话示例 | 对应说明 |
| :--- | :--- | :--- |
| **借钱给别人** | `@Bot 我借给 @张三 100元 吃饭AA` 或 `@Bot 狗子 欠我 50` | 记录对方欠我指定金额，等待对方确认 |
| **垫付记账** | `@Bot @李四 欠我 50 块 打车费` | 记录李四欠我 50 元，等待李四确认 |
| **向别人借钱** | `@Bot 我向 @王五 借了 30 元 买奶茶` | 记录我欠王五 30 元，等待王五确认 |
| **还款抵扣** | `@Bot 我还给 @张三 50 块 微信已转` | 记录我还款给对方，冲减已有欠款 |
| **记录收到还款**| `@Bot @张三 还了我 33 元` 或 `@Bot 收到 狗子 还款 50` | 记录对方还钱给我，冲减已有欠款 |
| **一键全额结清**| `@Bot 我还清了 @张三` 或 `@Bot 结清 狗子` | **自动计算当前净欠款**并一键发起平账 |
| **绑定外号别名**| `@Bot 把 @张三 设置外号为 狗子` | 绑定后后续可直接用外号免@记账 |
| **确认同意** | `@Bot 同意` 或 `@Bot 同意 #101` | 被申请人同意并真实入库 |
| **拒绝申请** | `@Bot 拒绝` 或 `@Bot 拒绝 #101` | 被申请人拒绝申请并作废 |
| **撤销申请** | `@Bot 撤销` 或 `@Bot 撤销 #101` | 发起人在生效前撤回申请 |
| **查双人账** | `@Bot 查一下我和 @张三 的账目` 或 `@Bot 查账 狗子` | 输出双方实时净欠款与最近流水 |
| **查个人总账** | `@Bot 我的账单` / `@Bot 谁欠我钱？` | 跨群统计全局待收、待还及人员明细 |
| **使用帮助** | `@Bot 记账帮助` | 查看使用指南 |

## 📦 安装与配置

### 1. 安装方式

#### 方式一：Git 克隆到插件目录
进入 AstrBot 根目录下的 `data/plugins/` 文件夹：
```bash
cd data/plugins
git clone https://github.com/eskyfun/astrbot_plugin_debt_ledger.git
```

#### 方式二：AstrBot 管理面板安装
直接在 AstrBot Web 控制面板的「插件市场」中搜索 `astrbot_plugin_debt_ledger` 点击安装并重启。

---

### 2. 配置项说明

在 AstrBot 控制面板或 `_conf_schema.json` 中可自定义以下配置：

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `timeout_seconds` | `int` | `600` | 申请确认超时时间（秒，默认 10 分钟） |
| `currency_symbol` | `string` | `¥` | 账本中展示的货币符号 |
| `enable_natural_language`| `bool` | `true` | 是否启用自然语言 @机器人 记账支持 |
| `enable_llm_tool` | `bool` | `true` | 是否向大模型注册 Function Calling 工具 |
| `max_single_amount` | `float`| `1000000.0`| 单笔允许记录的最大金额上限 |
| `allow_self_debt_direct_record` | `bool` | `false` | **是否允许主动认欠款直接入账（免确认）**。<br>开启后，记录向他人借款/自己欠款时直接入库生效；记录他人欠我钱仍然必须对方确认。 |

## 🛠️ 技术架构

- **语言环境**：Python 3.10+ / AstrBot v4.0+
- **数据持久化**：SQLite 3（开启 WAL 日志模式与外键级联，支持高并发读写）
- **数据存储路径**：`data/astrbot_plugin_debt_ledger/ledger.db`
- **净额计算引擎（Netting Algorithm）**：
  $$	ext{Net Balance}_{A 	o B} = (	ext{Borrow}_{A	o B} - 	ext{Repay}_{B	o A}) - (	ext{Borrow}_{B	o A} - 	ext{Repay}_{A	o B})$$
